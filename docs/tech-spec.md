# 技术方案

## 整体架构

单文件 HTML 网页应用（`index.html`），所有 CSS 和 JS 内嵌。

## 技术选型

| 层级 | 选型 | 说明 |
|------|------|------|
| 结构 | HTML5 | 语义化标签 |
| 样式 | 内嵌 CSS3 | 不使用框架，纯手写 |
| 逻辑 | 原生 JavaScript (ES6+) | 无依赖，无构建工具 |
| 数据 | JS 内联数组 | 60-80 条 JSON 对象 |
| 图片 | 网络 URL + 本地文件 | 烟盒图用外链，头像用本地 prun.jpg |
| 字体 | CSS @font-face | 三款中文字体，异步加载 |
| 部署 | GitHub Pages | 免费静态托管 |

## 数据模型

```javascript
// 每款烟的数据结构
{
  id: 1,                    // 唯一编号
  name: "中华（软）",        // 产品名称
  brand: "中华",             // 品牌
  price: "50元以上",         // 价格档位
  origin: "国产",            // 国产/进口
  thickness: "常规",         // 常规/细支/中支
  mood: ["想放松一下"],      // 匹配的心情标签
  taste: ["抽点够劲的"],     // 匹配的口感标签
  image: "https://...",     // 烟盒图片URL
  description: "国烟经典"    // 一句话描述（用于推荐理由）
}
```

## 筛选算法

```
1. 初始化候选池 = 全部烟款
2. 遍历用户每道题的答案：
   a. 如果答案为「无所谓」或「都行」→ 跳过该题
   b. 否则，从候选池中过滤，保留匹配该答案的烟
   c. 如果过滤后剩余 < 3 → 忽略该题过滤（回退）
3. 从最终候选池随机抽取 3 款
```

## 页面切换逻辑

- 三个 `<div>` 区域：`#page-home`、`#page-quiz`、`#page-result`
- 同一时间只显示一个（`display: none/block` 切换）
- JS 维护当前状态：`currentStep`（0-4）、`answers`（数组）

## 字体加载策略

由于中文字体文件较大，采用以下策略：
- 优先使用系统字体渲染，保证快速显示
- 使用 CSS `@font-face` + `font-display: swap` 异步加载自定义字体
- 字体文件存放于 CDN 或项目中

## 浏览器兼容

- 目标：iOS Safari 12+、Android Chrome 80+、微信内置浏览器
- 不使用较新的 CSS 特性（如 Container Queries）
- JS 使用 ES6 基础语法（箭头函数、模板字符串、const/let）
