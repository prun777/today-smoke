# 烟盒图片下载指南

将下载的烟盒图片放入此文件夹，文件名**必须**与烟名完全一致。

## 图片要求

- 格式：JPG（推荐）或 PNG
- 建议尺寸：200×270 像素左右
- 每张图只拍一包烟的正面即可

## 推荐下载来源

以下网站可以搜到大部分烟的图片：

1. **觅元素** (51yuansu.com) — 搜索 "\<烟名\> png"
2. **红动中国** (redocn.com) — 搜索 "\<烟名\> 图片"
3. **图品汇** (88tph.com) — 搜索 "\<烟名\> 素材"
4. **站长素材** (chinaz.com) — 搜索 "\<烟名\> 图片"
5. **百度图片** (image.baidu.com) — 直接搜索烟名

## 提示

- 图片不需要一次性找齐，每找到一张就放进这个文件夹
- 刷新页面后，有图的烟会自动显示真图
- 没图的烟会显示带品牌名的彩色占位卡片
