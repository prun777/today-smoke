# 需求文档

## 项目名称

「今天抽什么烟」— 网站版

## 项目定位

趣味测一测今天适合什么风格的烟。以生活方式趣味问答形式呈现，不涉及购买链接、不鼓吹吸烟、不展示烟草广告。

## 目标用户

手机端用户（微信内打开或浏览器打开），对烟草有基本认知的成年人。

## 核心功能

### 问答流程

用户通过 5 轮选择题，系统用排除法逐步缩小候选范围，最终随机推荐 3 款匹配的烟。

### 5 个提问维度

| 顺序 | 问题 | 选项 |
|------|------|------|
| 1 | 今天的预算？ | 20元以下 / 20-50元 / 50元以上 / 无所谓 |
| 2 | 国产还是进口？ | 国产 / 进口 / 都行 |
| 3 | 喜欢什么粗细？ | 常规烟 / 细支 / 中支 / 无所谓 |
| 4 | 今天心情如何？ | 想放松一下 / 一个人呆着 / 和朋友在一起 / 无所谓 |
| 5 | 偏好什么口感？ | 抽点够劲的 / 抽点柔和的 / 抽点甜的 / 抽点口水烟（少尼古丁）/ 无所谓 |

### 排除法规则

- 每选一题，从候选池筛掉不匹配的烟
- 若某步后剩余 <3 款，忽略该题选择（回退，保留之前的结果）
- 最终从剩余候选中随机抽取 3 款

### 进口烟规则

- 进口烟默认不在候选池
- 仅当第 2 问选「进口」或「都行」时才进入候选

### 结果展示

- 3 张推荐卡片，每张含：烟盒图片、烟的名称/品牌、一句匹配理由
- 「再测一次」按钮

## 数据范围

- 主流品牌，约 60-80 款
- 国产为主（约 50-60 款），进口为辅（约 10-20 款）
- 每款烟字段：名称、品牌、价格档位、粗细、国产/进口、口感标签、心情标签、烟盒图片 URL

## 非功能性需求

- 单文件，零依赖，浏览器直接打开
- 手机端优先（响应式设计）
- 页面加载快（字体异步加载）
