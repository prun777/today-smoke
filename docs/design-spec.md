# UI 设计规范

## 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FAF7F2` | 米白色，温暖柔和 |
| 文字颜色 | `#000000` | 纯黑，保证可读性 |
| 按钮背景 | 蓝色（待定具体色值） | 醒目但不刺眼 |
| 按钮文字 | `#FFFFFF` | 白色，与蓝色背景对比 |

## 字体

| 层级 | 字体 | 说明 |
|------|------|------|
| 标题 | 标小智龙珠体 | 页面主标题「今天抽什么烟」 |
| 按钮 | 素材集市社会体 | 所有按钮文字 |
| 正文 | 抖音美好体 | 问题文字、选项、推荐理由等 |

## 页面布局

### 通用规则

- 最大宽度 480px（手机友好），居中显示
- 大量留白，内容不拥挤
- 页面切换用显示/隐藏，不跳转

### 首页

- 标题「今天抽什么烟」居中，大字
- 「开始」按钮居中，蓝色
- 右下角固定：公众号推广组件
  - 圆形头像（prun.jpg）
  - 文字"prun"
  - 文字"关注微信公众号"

### 问答页

- 问题文字居中偏上
- 选项按钮竖向排列，每个占满宽度（留适当边距）
- 按钮大号点击区域（最小 48px 高）
- 不显示进度数字

### 结果页

- 「今日推荐」标题
- 3 张卡片竖向排列
- 每张卡片：烟盒图（左）+ 烟名/品牌/理由（右）
- 底部「再测一次」按钮

## 交互动效

- 页面切换：简单淡入（可选，不强制）
- 选项点击：按钮变色反馈
- 不花哨，保持克制

## 响应式

- 桌面端：内容居中，最大宽 480px
- 手机端：占满屏幕宽度，左右各 16px 边距
